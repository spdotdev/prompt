# Security Policy

PROMPT is a static, client-side-only mockup with no backend, no auth, and no user data — the attack surface is limited to the built static site and its build/CI pipeline.

## Reporting a Vulnerability

If you find a security issue (e.g. a supply-chain problem in a dependency, an XSS-style issue in how mock content is rendered, or a CI/workflow misconfiguration), please report it privately via [GitHub Security Advisories](https://github.com/spdotdev/prompt/security/advisories/new) rather than opening a public issue.

You can expect an initial response within a few days. There's no bug bounty — this is a small open-source demo project.

## Supported Versions

Only the `main` branch is maintained; there are no released versions to track.
